      How we build it

      Five rules it is built by

      An agent that governs AI has to be held to a higher standard than the AI it is checking. These are the commitments in the design.

      01

      Read-only first

      It connects with read access only. It proposes changes and people make them.

      02

      Rules score. The model investigates.

      A fixed rule sets every score, so the same evidence always gives the same result. The model does the searching and the explaining, never the scoring.

      03

      No finding without evidence

      Each finding links to the records behind it. If it cannot be evidenced, it is reported as unknown, not guessed.

      04

      Regulation is a pack

      The rules are one foundation. The regulation is configured per market, so a new market is a new pack, not a rebuild.

      05

      Governed like any agent

      We hold the agent to our own Sentinel questions: what it can see, what it can change, and whether every action can be reconstructed.

      The same foundation. Your regulator.
