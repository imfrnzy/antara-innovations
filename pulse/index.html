Setup in a few minutes

Connect PulseX to your Cliniko account

PulseX works with the Cliniko account you already use. You give it a key once, and it reads your diary, patients, notes and invoices straight from Cliniko.

  1. Open your details in Cliniko. Open your name at the top right, then choose “My info”.
  2. Create an API key. Scroll to “Manage API keys” and choose “Add API key”. Copy the key.
  3. Paste it into PulseX. Paste the key into “Cliniko API key”.
  4. Tap Connect. PulseX checks the key with Cliniko and you are straight in.

Your records stay in Cliniko. PulseX reads them live. Your key is stored encrypted. You can disconnect any time from More in the app, and you can remove the key in Cliniko to cut it off everywhere.
