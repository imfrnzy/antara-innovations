How it is held to account

Rules, not vibes

01

Three scores, highest wins

Regulation, data and reversibility are scored separately. The overall rating is the highest, never an average.

02

Records beat opinions

A tool that appears in the records is on the map, whoever declared it.

03

New tools raise a flag

Each run is compared with the last. Anything new is flagged.

The agent is held to the same questions it asks of everyone else.
