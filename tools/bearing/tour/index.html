Every AI use raises the same question eventually

A supervisor, an auditor or a client asks who's accountable for a specific AI decision. The honest answer is usually "several people, informally", which in practice means no one.

How it is held to account

Rules, not vibes

01

A yes is not evidence

An answer counts only when the document behind it can be produced.

02

One accountable person

Split or missing ownership is reported as a finding, not smoothed over.

03

Changes are tracked

When the regulation or the evidence changes, the supervisor pack changes.

The agent is held to the same questions it asks of everyone else.
