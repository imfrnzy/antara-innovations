MANIFEST

A ship's manifest is the record that has to be accurate before the voyage is allowed to continue.

Funding runs out quietly. Then the report is due yesterday.

Insurers fund therapy a block of sessions at a time. Past that point they want a structured progress report before they approve more, and they can take a few working days to decide. Most clinicians find out the funding has run out when the next session is already booked, then write the report from scratch, on their own time.

So Manifest keeps a file for each client

Add the client once

A short code, the insurer, and how many sessions they have approved. Never a name.

Log each session

The date, PHQ-9 and GAD-7 if you use them, and one line on how it went. About 30 seconds.

Come back any time

Sign in with your email and everything is there. Nothing to retype.

And it watches, so you don't have to

Counts the funded sessions

When two are left it tells you, so the request goes in before there is a gap, not after.

Watches the scores

It flags a client whose scores have risen past the NHS reliable-change threshold, or have not moved after four scored sessions. It reports the numbers. The judgement is yours.

Emails only you

A short note with the client code and a headline. No names, no scores, and never to an insurer.

The numbers aren't guessed. They're calculated.

Manifest works out reliable improvement and recovery itself, using the same point-change thresholds NHS Talking Therapies uses for PHQ-9 and GAD-7. A drop of 6 or more on the PHQ-9, 4 or more on the GAD-7, that's reliable improvement, by a fixed rule, not an AI's impression of your notes.

The model only writes the sentences around that number. It never gets to decide what the number means.

When the request is due, the report is half written

One button builds the report form from the client file and the sessions you logged. Your own session lines become the progress section. The session count, latest scores and last session date fill themselves in.

The risk details are left blank on purpose, because they have to be current. Before it drafts, Manifest checks the report against what Bupa and AXA are documented to ask for, so a gap shows up before the insurer finds it. You read it, change anything, and send it yourself.

If the insurer comes back with a query

Paste their question in. Manifest drafts a reply from that client's file, and lists what it could not find there.

It is told to use only what is in the file. Where the file is silent it leaves a gap for you to fill, and does not guess. Take any client name out of the query before you paste it.

What it will not do

Contact an insurer

Nothing is ever sent for you. The report is yours, and you press send.

Ask for a name

A short reference only. Initials or a case code, nothing that identifies your client.

Decide anything clinical

It reports numbers against published NHS thresholds. Your clinical judgement comes first, always.

Where what you type goes

It is stored against your email address so it is there next time. When you ask for a draft, the text for that request goes to an AI service to write the report. Nothing goes to an insurer.

You can delete any client and their sessions yourself. Manifest is in early use, so until you are comfortable, use a short code and keep identifying detail out of the free-text boxes.
